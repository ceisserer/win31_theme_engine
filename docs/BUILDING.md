# Building and running

## Requirements (Linux)

* gcc, make, Python 3 (only for `tools/`)
* [Open Watcom C/C++ 2.0](https://github.com/open-watcom/open-watcom-v2) for the Windows 3.x binaries:

  ```sh
  curl -sSL -o ow.tar.xz https://github.com/open-watcom/open-watcom-v2/releases/download/Current-build/ow-snapshot.tar.xz
  sudo mkdir -p /opt/watcom && sudo tar xJf ow.tar.xz -C /opt/watcom
  ```

## Targets

| Command | Result |
|---|---|
| `make host` | `build/host/preview` (theme previewer) and `build/host/rttest` (test suite) |
| `make test` | runs the host test suite: INI parser, theme loader, layouts, glyphs, golden images |
| `make preview` | renders every theme in `themes/` to `build/preview/<THEME>/*.png` |
| `make update-golden` | rewrites `host/tests/golden/*.png` after an intended rendering change (review the diff) |
| `make win16` | `build/win16/RETHEME.DLL`, `RETHEME.EXE`, the test program `GALLERY.EXE` and the installer `SETUP.EXE` (from the submodule `external/win16setup`; set `WATCOM=` if not `/opt/watcom`) |
| `make release` | the release packages in `build/release/` (see below) |

GitHub Actions (`.github/workflows/build.yml`) installs the current Open Watcom snapshot, runs `test` and `release`
on every push and pull request and keeps the packages, the Win16 binaries and the previews as build artifacts. Pushes
to the default branch also replace the rolling pre-release
[`snapshot`](https://github.com/ceisserer/win31_theme_engine/releases/tag/snapshot) (version `X.Y.Z-snapshot.<commit>`;
locally: `make release RELEASE_VERSION=X.Y.Z-SUFFIX`). The build needs no licensed material.

## Installing on Windows 3.1

Releases (GitHub Releases) contain `retheme16-X.Y.Z.zip` and a 1.44 MB floppy image with the same files. Unzip
(or insert the disk) and run `SETUP.EXE`. Setup shows a preview of each theme, copies the files (default
`C:\RETHEME`), writes `RETHEME.INI`, adds `RETHEME.EXE` to `load=` in `WIN.INI` (optional), creates a Program
Manager group (optional) and starts the engine. Run it again to change the theme or to remove Retheme16.

```
SETUP /S [/D=C:\RETHEME] [/T=WIN95] [/NOLOAD] [/NOGROUP] [/NOSTART]    silent install
SETUP /U [/S]                                                         remove
```

Setup logs to `SETUP.LOG` in the installation directory (`W16UNINS.LOG` in TEMP when removing). A running engine
is stopped before files are replaced.

By hand: copy `RETHEME.EXE`, `RETHEME.DLL` and `THEMES\` into one directory and run `RETHEME.EXE` (or
`RETHEME.EXE C:\RETHEME\THEMES\<NAME>` for another theme). It stays as an icon; closing the icon unloads the
engine and restores the Windows 3.1 look. Diagnostics go to `RETHEME.LOG`. The theme is set in `RETHEME.INI`:

```ini
[Engine]
Theme=C:\RETHEME\THEMES\WIN95
```

Requirements: Windows 3.1 or Windows for Workgroups 3.11 in Standard or 386 Enhanced mode.

`GALLERY.EXE` (the Theme Gallery) opens test scenes: `GALLERY dialog styles msgbox` shows the controls dialog, one
window per caption style and a message box.

## Making a release

| Step | What it does |
|---|---|
| `make release` | builds everything and packages `build/release/`: `retheme16-X.Y.Z\` (the installation files with `SETUP.INF` and theme previews), `retheme16-X.Y.Z.zip`, `retheme16-X.Y.Z-disk.img`, `SHA256SUMS`, `RELEASE_NOTES.md` (from `CHANGELOG.md`). Needs Python with Pillow and mtools. The ZIP and the disk image are reproducible (dates from the last commit). |
| `tools/release/release.sh [--emu BASE-IMG] [--push]` | checks the tree, `VERSION` and `CHANGELOG.md`, runs the tests and `make release`, optionally the QEMU install test (`tools/emu/test_setup.py`), tags `vX.Y.Z` and pushes the tag |
| `.github/workflows/build.yml` | on a pushed `v*` tag (must match `VERSION`): builds, tests, packages and publishes the GitHub release with the ZIP, the disk image and the checksums (0.x as pre-release). Where tags cannot be pushed, a branch push whose commit message starts with `Release vX.Y.Z`, or starting the workflow by hand with "release" ticked, releases that commit and GitHub creates the tag. |

To release: set `VERSION`, add a `## X.Y.Z` section to `CHANGELOG.md`, commit, then `tools/release/release.sh
--push`.

The installer is [Win16Setup](https://github.com/ceisserer/Win16Setup), a separate project included as the git
submodule `external/win16setup` (clone with `--recurse-submodules`, or run `git submodule update --init`).
Retheme16's configuration is `dist/SETUP.INF` (texts, theme choice with previews, `RETHEME.INI`, autostart, Program
Manager group, programs to stop); `tools/release/mkrelease.py` stages the files and theme previews and runs
Win16Setup's packer (`external/win16setup/tools/w16pack.py`). The `RETHEME.EXE` icon is generated by
`tools/gen_icons.py`.

## Testing in an emulator

`tools/emu/` builds a DOS + Windows 3.1 disk image from the installation disks (unattended) and runs scripted
sessions in QEMU with screenshots; see [tools/emu/README.md](../tools/emu/README.md).
