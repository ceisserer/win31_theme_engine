# Changelog

## Unreleased

* Without a colour scheme (no `[colors]` in `WIN.INI`) Windows takes its colours from the display driver, and
  some drivers have their own: with vbesvga.drv (16 and 24-bit colour in QEMU and on modern cards) the caption
  was sky blue with black text and the selection light blue, so the Windows 95, 98 and ME themes looked wrong.
  The engine now uses the colours of Windows 3.1 instead (navy caption and selection, white text) while it runs,
  for the colours the theme does not set itself, except the desktop. A colour scheme chosen in Control Panel is
  left as it is.
* New theme `WIN11`, "Redmond-11": the light look of Windows 11 (a light caption with dark text, rounded window
  corners, flat caption buttons with a red pressed close button, white rounded push buttons with a blue default
  button, blue check boxes and radio buttons, thin rounded scroll bar thumbs, light menus with a rounded grey
  highlight, the Windows 11 light colours). Made for 16-bit high-colour displays; self-contained. Bitmaps are
  generated by `tools/gen_win11.py`. `[Shell] Style=11` switches NewShell16 to its Windows 11 taskbar and Start
  menu.
* Push button labels get the button's state: `PushButtonText.Default` (and `DefaultPressed`) can give the default
  button's label its own colour; themes without them are unchanged (fallback to `Normal` and `Pressed`).
* New theme `WINXP`, "RedmondExperience": the Windows XP "Luna" look (blue caption with rounded top corners, round
  caption buttons with a red close button, rounded push buttons, green check marks, light blue scroll bars, white
  menus, the Luna colours). Made for 16-bit high-colour displays; works at 256 and 16 colours. Self-contained, so
  only one theme is loaded. Bitmaps are generated by `tools/gen_winxp.py`.
* Themes can carry a `[Shell]` section for shells: `Style=XP` switches NewShell16's taskbar and Start menu to the
  same look.
* System colours of a theme (`[SysColors]`) are snapped to solid colours on 256-colour displays too.
* Push button focus rectangle: it no longer runs through the label of low buttons (e.g. Control Panel's Ports
  dialog, the About box of NewShell16); with `WINXP` it sits 3 pixels inside the button as in Windows XP. The
  theme's `[Focus] Inset` is now measured from the button edge (`WIN95`: 4).
* Emulator tests: `regress.sh` takes `THEME=`; golden set `win31hc-xp` (800×600, 65536 colours, VBE driver).

## 0.1.0

First release: the Windows 95 look for Windows 3.1 and Windows for Workgroups 3.11.

* Title bars and window frames: Windows 95 caption buttons (minimize, maximize/restore, close), icon, bold
  left-aligned title, active and inactive states.
* Dialogs: grey background, Windows 95 push buttons, check boxes and radio buttons, etched group boxes, sunken
  edit and list boxes, drop-down list combo boxes, message boxes with MS Sans Serif.
* Menus: grey menu bar and popup menus with 3D border, highlight bar, etched separators, system menu.
* Scroll bars: window, list box and scroll bar controls with Windows 95 arrows, thumb and track.
* Themes: `WIN95` (default), `WIN98` (gradient title bars), `SLATE` (example of a bitmap theme); themes are INI
  files, see `docs/THEME_FORMAT.md`.
* Safety: the engine removes its patches before Windows shows a system error box; closing the Retheme16 icon
  restores the Windows 3.1 look.
* Setup: graphical installer ([Win16Setup](https://github.com/ceisserer/Win16Setup)) with theme preview,
  `WIN.INI` autostart, Program Manager group, silent install (`SETUP /S`) and removal (`SETUP /U`).

Tested in QEMU on Windows 3.1 (US English, German, debug kernel), Windows for Workgroups 3.11, VGA 16 colours and
VBE SVGA 256 colours. Not yet tested: real hardware, other display drivers, large fonts, Standard mode.

Known gaps: see `docs/STATUS.md` (controls outside dialogs, simple and drop-down combo boxes, MDI children, the
desktop and icon titles keep the Windows 3.1 look).
